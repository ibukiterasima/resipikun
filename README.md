# スーパーレシピくん

自分のレシピを保存・管理しながら、みんなが公開したレシピを探したり、気に入った料理を保存したりできる「レシピSNS」です。

「探す」「保存する」「自分で作る」「公開する」「人をフォローする」を、ひとつのサービスにまとめています。

- 公開先：GitHub Pages（無料）
- データ保存：Supabase（無料プラン）
- 作りは `index.html` 1ファイルだけ（フレームワーク・自前サーバーなし）

## 主な機能

| 機能 | 内容 |
|---|---|
| 公開レシピ | 投稿されたレシピを縦に並べて表示。ログインしなくても閲覧できる |
| いいね／保存／Myレシピに追加 | 「あとで見る」は保存、「自分のレシピ帳に入れる」はMyレシピ、と使い分け |
| Myレシピ | 自分だけのレシピ帳。編集・削除・公開ができる |
| レシピの投稿 | 料理名・材料・作り方・タグは必須、写真は任意。作り方は改行すると番号が自動でつく |
| 検索 | 料理名・タグ・投稿者名で検索 |
| おすすめ | 検索・Myレシピ追加・いいね・保存などの行動から興味を学習し、好みに合うレシピが上に出やすくなる |
| フォロー | 気に入ったユーザーをフォロー。マイページで一覧を確認できる |
| マイページ | プロフィール編集、保存したレシピ、公開したレシピの管理、ログアウト |
| ログイン | メールアドレスを入力するだけ（初回のみユーザー名を登録） |



## ファイル構成

```
index.html   サイト本体（画面・処理がすべて入っている）
setup.sql    Supabaseに必要なテーブルを作るSQL
icon.jpg     ファビコン（タブやホーム画面のアイコン）
README.md    このファイル
```


## 使っている技術

- HTML / CSS / JavaScript（フレームワークなし）
- [Supabase](https://supabase.com)（データベース）
- [GitHub Pages](https://pages.github.com)（公開）
- フォント：Zen Maru Gothic（Google Fonts）
